Порядок работы, по шагам (не делай всё сразу, спрашивай подтверждение
после каждого шага):

1. Расширь карточку персонажа в app.js под все поля:
   внешность (описание + фото, фото сохраняй как base64-строку прямо
   в объекте персонажа), характер, биография, цели/мотивация,
   речевые особенности.
   Добавь:
   - "арку" персонажа — заметки по главам (объект вида
     { chapterId: "заметка" } внутри персонажа, либо отдельный массив
     связей персонаж-глава)
   - связи между персонажами (массив {targetCharacterId, relationType,
     description} внутри персонажа, отображать в его карточке списком
     "Отношения" с возможностью добавить/удалить связь)
   - привязку персонажа к сюжетным веткам (аналогично, массив id веток)

2. Добавь новую вкладку "Заметки" (лор, исследования, идеи):
   - объект заметки: { id, title, text, tags: [], images: [], links:
     { characterIds: [], chapterIds: [], branchIds: [] }, createdAt,
     updatedAt }
   - теги пользователь создаёт и редактирует сам (не фиксированный список) —
     облако тегов сверху экрана, клик по тегу фильтрует список заметок
   - в каждой заметке — возможность привязать её к нескольким персонажам,
     главам и/или веткам (мультивыбор из уже существующих), без ограничения
     по количеству заметок на один элемент
   - на карточке заметки внизу показывай значки/чипы связанных элементов
   - поле поиска по тексту и заголовку заметок
   - сортировка списка: по дате создания, по дате изменения, по алфавиту
   - прикрепление изображений к заметке (base64, как и фото персонажей)
   - CRUD целиком: создание, редактирование, удаление заметки

3. Добавь историю версий для глав:
   - структура: chapter.versions = [{ id, label, timestamp, text }]
   - кнопка "Сохранить версию" рядом с редактором главы — при клике
     запрашивает опциональное название (prompt), сохраняет снимок текущего
     текста главы в chapter.versions (не более одного клика — не путать
     с автосохранением самого текста, которое остаётся как есть)
   - в интерфейсе главы — список версий (название + дата), клик по версии
     показывает построчный/word-level diff между этой версией и текущим
     текстом (используй библиотеку jsdiff — https://cdnjs.cloudflare.com,
     пакет diff — diffWords или diffLines): добавленное подсвечивается
     зелёным, удалённое — красным зачёркнутым
   - кнопка "Восстановить эту версию" — заменяет текущий текст главы
     текстом выбранной версии (текущее состояние перед этим стоит
     тоже сохранить как автоматическую версию, чтобы не потерять)

4. Сделай отдельную мобильную вёрстку (не просто адаптив десктопной):
   нижняя навигация вместо боковой панели при ширине экрана < 768px,
   полноэкранный редактор главы, крупные зоны нажатия. Проверь на
   разных размерах экрана через DevTools.

5. Добавь резервное копирование в Google Drive (ТОЛЬКО по явному клику,
   без автоматики и без debounce-таймеров):
   - используй Google Identity Services + Google Drive API (drive.file scope
     — доступ только к файлам, созданным самим приложением)
   - потребуется Client ID из Google Cloud Console — оставь это как
     конфигурационное значение (например в отдельном config.js или
     переменной в начале app.js), я вставлю его сама после того, как
     заведу проект в Google Cloud Console; на этом шаге просто покажи
     мне, что именно нужно будет туда вписать
   - кнопка "Сохранить в Google Drive" — по клику отправляет точную копию
     данных проекта (тот же формат, что при обычном экспорте) в файл на
     Google Drive пользователя
   - кнопка "Загрузить из Google Drive" — по клику находит последний
     сохранённый файл-бэкап и восстанавливает из него данные (с
     подтверждением перед перезаписью текущих локальных данных)
   - рядом с кнопками показывай время последнего успешного бэкапа
   - НЕ вешай это на debounce/автосохранение — только явные клики

7. Добавь экспорт в Word (.docx):
   - используй библиотеку docx (https://docx.js.org, доступна через CDN
     на cdnjs.cloudflare.com) для генерации настоящего .docx в браузере,

   - кнопка "Экспорт в Word" у каждой главы — выгружает только эту главу
   - отдельная кнопка "Экспорт всего романа в Word" на уровне проекта —
